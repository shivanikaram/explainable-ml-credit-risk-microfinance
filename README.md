# Explainable Machine Learning Framework for Credit Risk Assessment in Microfinance

An explainable machine learning framework for credit risk assessment in microfinance institutions using field-estimable financial indicators.

## Project Overview

This project explores the use of machine learning to support credit risk assessment in microfinance settings where conventional financial information may be limited.

The system combines machine learning-based credit risk prediction with explainable AI techniques to provide interpretable insights into model predictions.

## Objectives

- Develop a machine learning model for credit risk assessment.
- Use financial indicators that can be estimated or collected in field-based microfinance environments.
- Apply explainable AI techniques to improve the interpretability of predictions.
- Provide an interactive interface for credit risk prediction.
- Support more transparent and understandable credit assessment decisions.
